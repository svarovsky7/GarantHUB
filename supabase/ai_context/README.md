# AI Context для базы данных GarantHUB

Эта директория содержит оптимизированные "выжимки" структуры базы данных для использования ИИ-ассистентами (Claude Code, Codex, GitHub Copilot).

## 📁 Файлы

### Основные файлы
- **ai_manifest.json** - Метаданные: дата генерации, хэши исходных файлов
- **ai_tables_min.json** - Компактное описание таблиц (~43KB)
- **ai_relations.json** - Связи между таблицами (73 FK)
- **ai_functions_min.json** - Сигнатуры функций
- **ai_triggers_min.json** - Описание триггеров
- **ai_enums_min.json** - Перечисления
- **ai_examples.sql** - Примеры SQL-операций

### Расширенные файлы
- **ai_tables_full.json** - Полное описание таблиц с индексами (~92KB)
- **ai_functions_full.json** - Расширенное описание функций

## 🔄 Генерация

Файлы автоматически генерируются из исходных данных:
- `supabase/exports/*.json` - Экспорты структуры БД
- `supabase/migrations/prod.sql` - Полная схема БД

```bash
# Перегенерировать AI-контекст
node scripts/generate-ai-context.mjs
```

## 🔑 Ключевые таблицы

### Основные сущности
- **projects** - Проекты
- **units** - Объекты (квартиры, помещения)
- **defects** - Дефекты
- **claims** - Претензии
- **court_cases** - Судебные дела
- **letters** - Письма

### Связующие таблицы
- **claim_units** - Претензии ↔ Объекты
- **claim_defects** - Претензии ↔ Дефекты
- **court_case_claims** - Судебные дела ↔ Претензии

### Вспомогательные
- **attachments** - Вложения
- **statuses** - Статусы
- **profiles** - Профили пользователей

## ⚡ Оптимизированные VIEW

### claims_summary
Агрегированная информация о претензиях с полями:
- `unit_ids`, `unit_names`, `building_names` - Связанные объекты
- `defect_ids` - Связанные дефекты
- `attachments_count` - Количество вложений
- `engineer_name`, `created_by_name` - Имена пользователей

### defects_summary
Агрегированная информация о дефектах с полями:
- `claim_ids` - Связанные претензии
- `unit_ids`, `unit_names`, `building_names` - Связанные объекты
- `project_ids`, `project_names` - Связанные проекты
- `has_pretrial_claim` - Флаг досудебной претензии

## 📝 Примечание

Foreign Keys восстановлены из имен constraints с помощью эвристик, так как в экспорте БД они заменены на `None.None(None)`. Точность: ~95%.
