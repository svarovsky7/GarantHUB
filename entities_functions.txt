Function Inventory – Entities
- src/entities/attachment/attachment.ts: `slugify` normalises file names, helper `upload` pushes blobs to Supabase Storage, `uploadLetterAttachment`/`uploadCaseAttachment`/`uploadTicketAttachment`/`uploadEngineerCallAttachment`/`uploadClaimAttachment`/`uploadDefectAttachment` route files into scoped folders, `addCaseAttachments`/`addLetterAttachments`/`addTicketAttachments`/`addClaimAttachments`/`addDefectAttachments`/`addUnitAttachments` persist attachment rows and return metadata, `getAttachmentsByIds` fetches attachment records in bulk, `updateAttachmentDescription` edits descriptions, `removeUnitAttachment`/`removeArchiveAttachment` clean up link rows and blobs, `signedUrl`/`signedUrlForPreview`/`getFileSize` wrap signed URL + HEAD probes, exported `ATTACH_BUCKET` exposes the resolved storage bucket name.
- src/entities/brigade/brigade.ts: `sanitize` trims payloads before persistence, `insert`/`patch`/`remove` wrap Supabase CRUD on the `brigades` table, `useBrigades` lists brigades with react-query caching, `useAddBrigade`/`useUpdateBrigade`/`useDeleteBrigade` provide mutation hooks that invalidate the brigade cache.
- src/entities/claim/lib/claimHelpers.ts: `closeDefectsForClaim` closes linked defects when a claim hits a closed status, `markClaimDefectsPreTrial` toggles the pre-trial flag on claim-defect links.
- src/entities/claim/lib/claimTransformers.ts: `signedUrl` and `signedUrlForPreview` generate short-lived Supabase URLs for claim attachments.
- src/entities/claim/model/mappers.ts: constants `TABLE`/`SUMMARY_TABLE`/`LINK_TABLE` centralise table names; `mapClaimSummary` converts summary rows into dayjs-aware objects; legacy `mapClaim` hydrates full claim rows including attachments and relations.
- src/entities/claim/model/useClaimQueries.ts: `useClaimsSummary` streams the `claims_summary` view with project scoping; `useClaims` is the older full-join fetch; `useClaim` and `useClaimAll` load a single claim (with/without project filters); `useClaimsAllSummary`/`useClaimsAll` deliver paginated admin views; `useClaimsAllLegacy` toggles the legacy pipeline; `useClaimsSimpleAll`/`useClaimsSimple` supply lightweight lists; `useClaimIdsByDefectIds` resolves claim IDs linked to selected defects.
- src/entities/claim/model/useClaimAttachments.ts: `useClaimAttachments` lists attachments for a claim, `useRemoveClaimAttachment` removes a single attachment with cache invalidation, `removeClaimAttachmentsBulk` deletes many rows plus blobs, `useAddClaimAttachments` uploads new files and links them to the claim.
- src/entities/claim/model/useClaimLinks.ts: `useClaimLinks` queries the `claim_links` table, `useLinkClaims` rewires child links to a parent with chunked deletes/inserts, `useUnlinkClaim` detaches a child claim from its parent.
- src/entities/claim/model/useClaimMutations.ts: `useCreateClaim` inserts claims, links units/defects, uploads attachments, and closes defects when required; `useUpdateClaim` patches claims and rewrites unit links with subsequent cache invalidation; `useDeleteClaim` cascades attachment cleanup, related defect file removal, and claim row deletion.
- src/entities/claim/model/useClaimStats.ts: `useClaimsAllStats` counts open/closed claims globally, `useClaimsStats` computes the same metrics within the active project filter.
- src/entities/claimStatus/claimStatus.ts: `useClaimStatuses`, `useAddClaimStatus`, `useUpdateClaimStatus`, `useDeleteClaimStatus` are thin wrappers over the generic status hooks bound to the `claim` entity.
- src/entities/contractor/contractor.ts: helper `sanitize` trims input fields, `findDuplicate` guards against duplicate INNs, `insert`/`patch`/`remove` perform Supabase CRUD, and `useContractors` plus `useAddContractor`/`useUpdateContractor`/`useDeleteContractor` expose list/mutation hooks with invalidation.
- src/entities/contractorCompletion/contractorCompletion.ts: `useContractorCompletions` fetches completions with contractor/project metadata and defect counts, `useContractorCompletion` loads a single completion, mutation hooks (`useAddContractorCompletion`, `useUpdateContractorCompletion`, `useDeleteContractorCompletion`) manage records, while `useCompletionDefects`, `useAddCompletionDefects`, and `useRemoveCompletionDefect` maintain linked defects.
- src/entities/correspondence/lib/contactResolver.ts: `getContactIds` resolves sender/receiver names to person/contractor IDs, `getSenderName` and `getReceiverName` perform the inverse lookup for display.
- src/entities/correspondence/lib/letterTransformers.ts: `extractFileName` derives a display name from storage paths, `transformAttachment` normalises raw attachment rows, and `signedUrl`/`signedUrlForPreview` provide signed access to letter files.
- src/entities/correspondence/model/useLetterLinks.ts: `useLetterLinks` lists existing letter relationships, `useLinkLetters` replaces child links in bulk, `useUnlinkLetter` removes a child letter link.
- src/entities/correspondence/model/useLetterMutations.ts: `useAddLetter` inserts a letter with derived sender/receiver contacts, `useUpdateLetter` patches metadata and contact links, `useDeleteLetter` removes a letter and its associations, `useUpdateLetterStatus` updates status, and `useUpdateLetterDirection` toggles incoming/outgoing direction flags.
- src/entities/correspondence/model/useLetters.ts: `useLetters` streams correspondence with project filters and denormalised fields, while `useLetter` loads a single letter with attachments and linked records.
- src/entities/courtCase/lib/courtCaseDefects.ts: `useCaseDefects` lists defects tied to a court case, `useAddDefect` links a defect, `useDeleteDefect` removes the link, and `useUpdateDefect` patches metadata inline.
- src/entities/courtCase/lib/courtCaseTransformers.ts: `mapCourtCaseSummary` builds dayjs-aware summaries, `signedUrl` fetches signed attachments, and `isCaseNumberUnique` checks Supabase for duplicate case numbers.
- src/entities/courtCase/model/useCourtCaseSummary.ts: `useCourtCasesSummary` paginates case summaries with project scoping for dashboards.
- src/entities/courtCase/model/useCourtCases.ts: `useCourtCases` retrieves full court-case records with filtering, `useCourtCase` loads a single case including relations.
- src/entities/courtCase/model/useCourtCaseMutations.ts: `useAddCourtCase`, `useUpdateCourtCase`, and `useDeleteCourtCase` wrap Supabase mutations plus cache invalidation; `useCaseLinks`/`useLinkCases`/`useUnlinkCase` manage parent-child case links; `useUpdateCourtCaseFull` orchestrates deep updates including related tables.
- src/entities/courtCaseClaim/courtCaseClaim.ts: `useCaseClaims` lists claim rows for a court case, and the trio `useAddCaseClaims`/`useUpdateCaseClaim`/`useDeleteCaseClaim` mutate the linking table.
- src/entities/courtCaseClaimLink/courtCaseClaimLink.ts: `useCaseClaimLinks` fetches case-claim link rows, `useAddCaseClaimLinks` inserts new links in bulk, `useDeleteCaseClaimLink` removes a specific link.
- src/entities/courtCaseParty/courtCaseParty.ts: `useCaseParties` and `useCasePartiesByCaseIds` fetch parties, while `useAddCaseParties`, `useUpdateCaseParty`, `useDeleteCaseParty` mutate participants tied to a case.
- src/entities/courtCaseStatus/courtCaseStatus.ts: `useCourtCaseStatuses`, `useAddCourtCaseStatus`, `useUpdateCourtCaseStatus`, `useDeleteCourtCaseStatus` bind the generic status hooks to court cases.
- src/entities/courtCaseUid/courtCaseUid.ts: `useCaseUids` returns available UIDs, `getOrCreateCaseUid` inserts or returns an existing UID row, `isCaseUidUnique` validates uniqueness.
- src/entities/defect/lib/defectHelpers.ts: `mapDefectSummary` builds enriched defect summaries, `signedUrl` issues signed storage links for defect files, `removeDefectAttachmentsBulk` deletes multiple attachments and blob objects at once.
- src/entities/defect/model/useDefectMutations.ts: `useCreateDefects` bulk-creates defects, `useUpdateDefect` patches a single defect, `useDeleteDefect` removes a defect, `useAddDefectAttachments` uploads and links attachments, and `useRemoveDefectAttachment` handles attachment deletion.
- src/entities/defect/model/useDefects.ts: `useDefectsSummaryPaginated` paginates the summary view, `useDefects` returns full defect collections with filters, `useDefect` loads a single defect, `useDefectFileCounts` preloads attachment counts, `useDefectsByIds`/`useDefectsWithNames` fetch selected defects for lookups.
- src/entities/defectStatus/defectStatus.ts: `useDefectStatuses`, `useAddDefectStatus`, `useUpdateDefectStatus`, `useDeleteDefectStatus` are entity-specific wrappers over the shared status mutations.
- src/entities/defectType/defectType.ts: `useDefectTypes` lists defect types, and `useAddDefectType`/`useUpdateDefectType`/`useDeleteDefectType` provide CRUD with cache invalidation.
- src/entities/document/document.ts: `useDocuments` fetches all documents with folder metadata, `useDocumentsByFolder` filters by folder id, `useCreateDocument` uploads metadata, `useUpdateDocument` patches titles/folders, `useDeleteDocument` removes entries, `useDownloadDocument` builds signed download links, `usePreviewDocument` fetches preview URLs, and `useUpdateDocumentFolders` reassigns one or more documents to chosen folders.
- src/entities/documentFolder/documentFolder.ts: `useDocumentFolders` lists folders, `useDocumentFoldersByProject` scopes folders to a project, and `useCreateDocumentFolder`/`useUpdateDocumentFolder`/`useDeleteDocumentFolder` wrap folder CRUD with invalidation.
- src/entities/engineerCall/engineerCall.ts: `useEngineerCalls` fetches calls within a date/project window, `useEngineerCall` loads a single call, mutation hooks (`useCreateEngineerCall`, `useUpdateEngineerCall`, `useDeleteEngineerCall`) manage lifecycle actions, `useEngineers` lists available engineers, `useEngineerCallAttachments` returns linked files, `addEngineerCallAttachments` uploads files, and `useDeleteEngineerCallAttachment`/`useUpdateEngineerCallAttachment` manage attachment removal/description updates.
- src/entities/lawsuitClaimType/lawsuitClaimType.ts: `useLawsuitClaimTypes` fetches lawsuit claim types, and the trio `useAddLawsuitClaimType`/`useUpdateLawsuitClaimType`/`useDeleteLawsuitClaimType` mutate them.
- src/entities/letterStatus/letterStatus.ts: `useLetterStatuses`, `useAddLetterStatus`, `useUpdateLetterStatus`, `useDeleteLetterStatus` bind the shared status hooks to correspondence letters.
- src/entities/letterType/letterType.ts: `useLetterTypes` lists letter categories, `useAddLetterType`/`useUpdateLetterType`/`useDeleteLetterType` mutate the lookup table.
- src/entities/person/person.ts: `usePersons` retrieves all persons, `usePersonsByProject` aliases the same hook, while `useAddPerson`, `useUpdatePerson`, and `useDeletePerson` provide CRUD with cache refresh.
- src/entities/project/project.ts: `useProjects` lists projects, helper `withInvalidate` wraps the Supabase mutations, and `useAddProject`/`useUpdateProject`/`useDeleteProject` use it for CRUD; `useVisibleProjects` returns the projects visible to the current user.
- src/entities/role/role.ts: `useRoles` downloads the roles lookup table with caching.
- src/entities/rolePermission/rolePermission.ts: `useRolePermissions` fetches all role permissions, `useRolePermission` fetches or falls back to defaults for one role, `useUpsertRolePermission` saves permission changes and invalidates caches.
- src/entities/status/status.ts: generic status toolkit—`useStatuses` lists statuses for an entity, `useEngineerCallStatuses` shortcuts the engineer call entity, while `useCreateStatus`, `useUpdateStatus`, `useDeleteStatus`, `useDefaultStatus`, and `useSetDefaultStatus` maintain status rows and default markers.
- src/entities/systemSettings/systemSettings.ts: `useSystemSettings` fetches all settings, `useSystemSetting` targets a single key, and `useUpdateSystemSetting` persists key/value updates.
- src/entities/unit/unit.ts: `useAllUnitsWithClaims`, `useUnits`, `useUnitsByProject`, `useUnitsByIds`, `useUnit`, and `useUnitsWithClaimsByProject` are various readers for units and their relationships; mutation hooks `useAddUnit`, `useUpdateUnit`, `useDeleteUnit`, `useDeleteUnitsByBuilding`, `useRenameBuilding` handle maintenance, while `useLockedUnitIds` and `useSetUnitLock` expose the locking workflow.
- src/entities/unitArchive/unitArchive.ts: helper `mapFile` normalises archive rows, and `useUnitArchive` assembles all attachment categories (unit, claims, defects, court cases, letters) for a unit with lazy size probes.
- src/entities/unitSortOrder/unitSortOrder.ts: `useUnitSortOrders` reads persisted sort directions per floor, `useUpsertUnitSortOrder` saves toggled directions to Supabase.
- src/entities/user/user.ts: `useUsers` lists profiles with joined projects, mutation hooks (`useUpdateUserRole`, `useDeleteUser`, `useUpdateUserProjects`, `useUpdateUserName`, `useChangePassword`, `useUpdateUserStatus`) update role, membership, name, password, and active flags; helper `addUserProfile` seeds a profile row with project links.
